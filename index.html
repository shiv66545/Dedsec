Dedsec runs locally

This website uses WebLLM and a small open model in your browser. The first launch downloads several hundred MB of model files and needs a modern browser with WebGPU support. After download, inference runs on your device; no paid AI API key is used. The model is small, so it cannot guarantee correct answers to everything or browse the live web.

Model loads only when you send your first message.
